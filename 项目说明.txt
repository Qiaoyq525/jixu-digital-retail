极序数码零售管理系统 · 项目说明

一、项目概述
本项目用于 Java 课程展示与答辩，包含前端页面、Java 后端、MySQL 数据库结构、测试和学习文档。
技术栈：Java 21、Spring Boot 3.5.16、MyBatis 3.0.4、MySQL 8.4、HTML/CSS/JavaScript。
支付采用课程模拟支付。

二、项目位置与运行
C:\Users\Q\Desktop\java\版本3

1. 在 IntelliJ IDEA 中选择 File → Open，打开整个“版本3”文件夹。
2. 等待 Maven 导入；未识别时，右键 pom.xml → Add as Maven Project。
3. Project SDK、Maven Importing 和 Runner 均选择 JDK 21，本机位置 D:\mecodingtool\jdk-21。
4. 确认本机 MySQL84 服务运行，连接配置位于 config/application-local.yml。
5. 运行 src/main/java/edu/shop/ShopApplication.java 中的 main 方法，工作目录为项目根目录。
6. 看到 Started ShopApplication 后，访问 http://localhost:8080。

也可以双击 start.cmd 启动；同一时间只启动一份使用8080端口的应用。
其他电脑缺少数据库配置时，按 README.md 运行 setup-database.cmd。

三、目录说明
src/main/java/edu/shop：Java 后端源码。
src/main/resources/static：前端页面、样式、脚本和本地商品图片。
src/main/resources/db/migration：Flyway V1至V5建表和升级脚本。
src/test/java：Java 测试源码。
config/application-local.yml：本机 MySQL 连接配置。
target/my-shop-2.0.0.jar：可执行程序。
docs：环境配置、数据库设计、业务规则、IDEA运行和代码讲解。
verification：最终测试报告与验收记录。

四、数据库
本机连接地址：127.0.0.1:3306；数据库名：my_shop_v2。
数据库迁移包含V1至V5。V5在Java启动时追加退款申请与审核字段，保留既有订单；具体日常数据库升级状态以启动日志为准。
业务数据由本机MySQL服务保存，项目目录保存建表与升级SQL及连接配置。
Java启动时自动检查并执行尚未应用的Flyway迁移。
开发预览8092使用独立MySQL3338，与IDEA默认连接的本机数据库数据独立。

六、主要功能
会员：设备查询、购物车、优惠试算、提交商品、订单查询和积分。
收银员：查看分配到本人柜台的会员提交，核对商品后确认结账；现场开单、订单查询；只能查看退款申请及审核结果，不能直接退款。
老板：商品分类、采购、库存、会员与员工、收银员管理、优惠、销售统计、日志和CSV导出。
收银员管理：创建员工账号、安排空闲柜台、启停员工；最多4个收银员账号（含停用），有待办时不能调岗或停用。
排队管理：限量抢购实验已移除，保留真实会员排队与人工确认。
会员提交后明确显示柜台、收银员和等待状态；对应收银员确认成功后才生成订单、扣库存并增加积分。
等待期间可取消，应用重启后等待票据保留；重复确认不会重复扣库存。
真实库存竞争继续通过隔离自动化测试核对，门店页面不再提供抢购实验。
