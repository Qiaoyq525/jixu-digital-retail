# 极序数码零售管理系统 · 完整项目

极序数码（JIXU DIGITAL）是用于 Java 课程展示与答辩的数码零售 Web 系统。老板乔胤淇（乔先生）管理门店，销售员负责收银和本人经手订单，会员浏览设备、加入购物车、排队结账、查看自己的订单与积分，并向老板申请退款。

这一版包含前端页面、Java 后端、MySQL 建表迁移、测试代码和阅读文档。前端使用你已确认的深蓝、青色风格，5 类共 14 款设备使用对应型号实物图；商品、购物车、优惠试算、订单、库存和积分均通过 Java 接口读写数据库。支付为课程模拟支付。

## 回来后先做这几步

本轮完整项目目录：

```text
C:\Users\Q\Desktop\java\版本3
```

1. 在 IntelliJ IDEA 中选择 **File → Open**，打开上面的整个文件夹。应能看到 `pom.xml`、`src`、`config` 和 `docs`。
2. 项目 SDK 选择 **JDK 21**，本机位置是 `D:\mecodingtool\jdk-21`。Maven Importing 与 Runner 也选择 JDK 21。
3. 等待 Maven 导入。如果没有识别，右键 `pom.xml` → **Add as Maven Project**。
4. 确认本机 `MySQL84` 服务运行。若项目已有 `config/application-local.yml`，先使用现有连接；缺少配置时才运行 `setup-database.cmd`，在本机输入 MySQL 管理员密码。
5. 打开 `src/main/java/edu/shop/ShopApplication.java`，点击 `main` 左边的绿色三角运行。工作目录选择项目根目录 `$PROJECT_DIR$`。
6. 看到 `Started ShopApplication` 后，浏览器访问 `http://localhost:8080`。

也可以双击项目根目录的 `start.cmd`。同一时间运行一份应用；准备改用 IDEA 时，先停止脚本启动的进程，避免 8080 端口占用。详细步骤见 [IDEA 打开与运行](docs/08-IDEA打开与运行.md) 和 [本轮交付与联调](docs/11-本轮交付与联调.md)。

## 本轮完成的内容

| 部分 | 当前实现 |
|---|---|
| 登录与权限 | 登录、会员注册、老板/销售员/会员三种身份、停用账号、会话和 CSRF 校验、BCrypt 密码哈希 |
| 会员选购 | 14 款实物图设备、分类与参数搜索、数据库购物车、确认订单、服务端优惠试算、排队结账、结果页、订单搜索和详情、会员积分 |
| 商品与库存 | 分类维护、商品增删改查、上下架、供应商、采购入库、库存流水、低库存提醒 |
| 收银与售后 | 收银台绑定员工、查看分配给自己的会员提交单、人工确认结账；另有现场选品收银、订单查询；会员申请整单退款，老板审核，收银员只读查看 |
| 门店管理 | 经营概览、销售趋势、热销商品、顾问业绩、优惠设置、操作日志、订单 CSV 导出 |
| 排队管理 | 持久化等待票据、明确柜台与收银员、人工确认、重启保留等待 |
| 收银员管理 | 老板创建收银员账号、安排空闲柜台、启停账号；收银员账号总数最多 4 个，含已停用账号 |
| 数据库升级 | Flyway V1 至 V5，实物图和订单快照、固定收银台与员工绑定、退款申请与审核字段 |

已有历史订单没有保存过的图片和规格保留为空，不会把当前手机图片倒填到旧商品订单。后续编辑商品名称或规格，不会改变新订单保存的购买时快照。自定义新商品可使用通用展示图；当前没有图片上传功能。

## 最新功能调整

管理员左侧增加“收银员管理”。默认的 `cashier1` 和 `cashier2` 占用两个名额，可以再创建两名收银员；创建时填写账号、姓名、密码并选择空闲柜台。新柜台会自动开放，员工可直接用新账号登录。调岗只允许选择空闲柜台；员工仍有待确认票据时，先完成或取消这些提交，再调岗或停用。公开“会员注册”仍只创建会员。操作与验收步骤见 [收银员管理与排队精简](docs/15-收银员管理与排队精简.md)。

“排队与并发”改为“排队管理”，已移除限量抢购实验页面及 `/api/queue/demo` 接口。订单防超卖、重复确认和退款的一致性检查继续保留在自动化测试中。下方测试数量是对应旧版本的历史结果，本次改动以最新验证记录为准。

会员可从“我的订单”或订单详情提交退款申请，填写原因后进入老板的“退款审核”。老板可批准或填写原因拒绝；收银员只能查看自己经手订单的申请和结果。申请、拒绝都不改变库存或积分，批准才执行整单退款。原直接退款入口已禁止执行，不能绕过申请。操作见 [会员退款申请与老板审核](docs/16-会员退款申请与老板审核.md)。

## 按这个顺序读 Java

先理解“页面发出请求 → Controller 接收 → Service 处理 → Mapper 执行 SQL → 返回 JSON → 页面更新”，再学习事务和线程。

1. `ShopApplication`：Java 程序入口。
2. `Product`、`CatalogController`、`CatalogService`、`CatalogMapper`：从熟悉的对象和字段开始，追踪一次商品查询。
3. `DiscountPolicy`、`AbstractDiscountPolicy`、`RateDiscountPolicy`、`DiscountCalculator`：接口、抽象类、继承、多态、优惠组合与简单工厂。
4. `OrderController`、`OrderService`、`CommerceMapper`：HTTP 参数、数据库事务、订单快照、幂等和库存锁。
5. `QueueController`、`QueueService`、`QueueMapper`：柜台分配、权限、人工确认和票据状态；结合 `CashierService` 理解新增账号、四人上限和调岗保护。
6. `AuthController`、`SecurityConfig`、`SessionUserFilter`：登录会话、角色和请求校验。
