## 手动验收数据核对

选择一个演示商品，记录开始库存 N，成功卖出 Q 件后库存应为 `N-Q`。会员申请或老板拒绝后仍为 `N-Q`；老板批准整单退款后才恢复 N。对应订单明细、库存流水应能一一对应。

会员记录开始积分 P、累计消费 S。实付 A 元、赠送 E 分后，积分应为 `P+E`，累计消费为 `S+A`。会员申请和拒绝后上述数值不变；批准退款后应回到本单交易前的数值，其他订单的数据不受影响。

隔离测试中每个并发购买请求只买一件且没有其他库存变化时：成功数 + 剩余库存 = 初始库存；库存不足的失败请求不产生已支付订单。不只观察页面成功提示，还需核对数据库或服务端结果。

## 测试执行方式

项目提供测试脚本时可在项目根目录执行：

```powershell
.\test.ps1
```

也可以在已配置 JDK 21 和 Maven 的环境执行：

```text
mvn verify
```

测试应使用隔离的 H2 库或专用测试数据库。不要为运行测试直接清空演示库或其他已有 MySQL 数据库。代码覆盖率只是辅助信号，不能用大量只检查 getter 的测试代替事务、权限与并发验证。
